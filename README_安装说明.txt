My Life OS · 第一版安装说明
================================

这个版本包含：
- 月历、按天查看事件
- 生活记录（文字、图片、视频）
- 任务管理和优先级推荐
- 周课表
- 学习目标与进度条
- JSON 数据导出/导入
- 每日提醒设置和浏览器通知（当前仅在应用打开期间检查）

重要限制（请先阅读）：
1. 这是可运行的第一版，不是已部署的云端服务。
2. 数据保存在当前浏览器的本机存储中。电脑和手机不会自动同步。
3. 媒体文件保存在本机浏览器存储中，容量取决于设备/浏览器。媒体暂不包含在 JSON 备份里。
4. 可靠的后台每日推送（即关闭浏览器仍准时收到）需要部署后端定时任务和 Web Push 服务；本版不会虚假宣称已具备该能力。
5. 要安装为 PWA，通常必须通过 HTTPS 网站打开（localhost 开发环境除外）。直接双击 index.html 可以预览，但安装和通知能力会受限。

最简单的本机预览：
- 解压整个 ZIP。
- 电脑安装较新的 Python 3。
- 在项目文件夹中打开终端，执行：
    python -m http.server 8000
- 浏览器访问：
    http://localhost:8000
- 不要直接双击 index.html 来测试安装能力。

安装到电脑（网站托管后）：
- 用 Chrome 或 Edge 打开 HTTPS 网站。
- 浏览器菜单中选择“安装 My Life OS”或“将此网站安装为应用”（不同版本文案可能不同）。

安装到 Android 手机（网站托管后）：
- 用 Chrome 打开 HTTPS 网站。
- 浏览器菜单选择“安装应用”或“添加到主屏幕”。
- 首次使用时允许通知权限（如浏览器提供该选项）。

跨设备使用：
- 目前是本机版本。若要电脑和手机共用同一份数据，需要下一阶段部署账号、云数据库和媒体存储。
- 不要把包含隐私的备份文件发给陌生人。
