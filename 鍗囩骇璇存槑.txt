My Life OS 3.0 学习工作台 · 第一阶段

【已实现】
1. 新增「AI 学习工作台」导航页（当前为本地学习管理工具，不是真实 AI 聊天）。
2. 大脑卸载箱：记录想法、转为原有待办任务。
3. 高数、线代、C 语言等知识点卡片、掌握程度、明日复习任务。
4. B 站、YouTube 等课程资源链接收藏与打开。
5. 成绩/学分记录和示例加权绩点（非学校官方算法）。
6. 任务接力：保存暂停点、生成恢复任务。
7. 原有日历、任务、课表、目标、成长档案与综测继续保留。
8. 更新离线缓存版本，减少 GitHub Pages 更新后仍显示旧页面的问题。

【尚未实现】
- 真正的 AI 对话、自动讲题、读取视频字幕、自动日程编排、账号与跨设备云同步。
- 这些需要安全的服务端 API 和云数据库，绝不能把 OpenAI API 密钥直接写入公开 GitHub Pages 的 JS 文件。

【更新步骤】
0. 先在旧网站的「设置与备份」导出 JSON，保存在安全位置。
1. 解压这个 ZIP，打开 MyLifeOS_3_upgrade 文件夹。
2. 进入 GitHub 仓库 Zora-hui777/my-life-os。
3. 选择 Add file -> Upload files，拖入文件夹内的文件（不是整个 ZIP）。
4. Commit changes；等 GitHub Pages 部署完成后刷新网站。
5. 进入左侧「AI 学习工作台」测试新功能。
6. 如果浏览器仍显示旧版，可先正常刷新/关闭后重开；不要清除网站数据，否则本地 IndexedDB 记录可能丢失。

【数据安全】
原网站使用 IndexedDB: MyLifeOSDB / kv / state；此次新增的数据存放在 state.mentor，不修改数据库版本，也不清空原数据。
更新网页文件本身不会迁移/同步手机与电脑的本地数据。
